## 📁 How It Works

1. Record current resolution, display mode and graphics-quality preset.
2. Choose one demanding but repeatable area and note your baseline frame rate and stuttering frequency.
3. Check whether high GPU usage or CPU load coincides with frame drops.
4. Lower graphics options one at a time—especially effects, shadows or water detail if available.
5. Compare frame caps and synchronization settings without changing several values together.
6. Retest after changes and keep the settings that improve consistency without unwanted image degradation.

## ❓ FAQ

**Q: Should I lower every setting to minimum?**  
A: Not necessarily. Changing one costly setting at a time makes the result easier to interpret.

**Q: Why does the game stutter only in certain areas?**  
A: Scene complexity and asset loading may vary; test more than one location.

## 🛠️ Troubleshooting

- Follow one diagnostic path at a time; note your starting settings so changes can be reversed.
- Check the current game or platform documentation before changing files or configuration.
- Keep a separate backup before restoring or replacing save data.
